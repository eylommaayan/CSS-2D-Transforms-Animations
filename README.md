## 📖 על הפרויקט

הבנת עקרונות ה-2D ב-CSS היא הבסיס החשוב ביותר למפתח Front-End לפני מעבר לפריימוורקים מורכבים.  
פרויקט זה כולל עמוד שער וניווט מרכזי (`index.html`) המקשר ל-6 מודולים נפרדים, שבהם כל קונספט מוצג בצורה חיה ואינטראקטיבית עם הסברים מפורטים בעברית.

## 📁 מבנה הקבצים בפרויקט

```text
├── index.html                     # עמוד השער הראשי עם רשת הקישורים לכל השיעורים
├── 01-transforms-basics.html      # ארבעת הבסיסים: scale, translateX, rotate, skew
├── 02-transform-origin.html       # שינוי ציר הסיבוב ונקודות עוגן (top left, פינות)
├── 03-advanced-2d-effects.html    # היפוכים מראתיים, שרשור טרנספורמציות וכפתורים
├── 04-kinetic-loader.html         # פרויקט Kinetic Loader (אנימציית משולשים קינטית)
├── 05-more-2d-animations.html     # אפקטי תנועה: Pulse, Physics Bounce, Orbit, Shimmer
├── 06-creative-2d-fx.html         # אנימציות יצירתיות: Typewriter, SVG Draw, Glitch, Radar
└── README.md                      # מדריך הפרויקט והתיעוד
